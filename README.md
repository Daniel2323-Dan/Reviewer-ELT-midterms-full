# ELT 121 Language Policy & Planning Reviewer

A responsive, mobile-friendly static study site for ELT 121. It includes **277 questions** (based on the updated uploaded course reviewer plus the custom Genesis question) and two practice modes: **Identification** (type the answer) and **Multiple Choice** (select one of four options). The question bank is filterable by topic and can be shuffled.

## Run locally
Open `index.html` in a modern browser. No dependencies or build tools are needed.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` (and this README if you like) to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
5. Open the Pages URL shown in repository settings.

All quiz code runs in the browser, so no server, account, API key, or internet connection is needed after the page is loaded.
